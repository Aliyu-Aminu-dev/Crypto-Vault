Crypto Vault is a mobile-first cryptocurrency wallet designed specifically for African users. Problem: Africans can't access crypto easily—websites slow on mobile, high fees, no local payment support. Solution: App works on any phone (even 3G), supports mobile money, $1 minimum purchases, <1% fees, educational content included. My Role: Designed 50+ mobile screens optimized for thumbs and slow networks; built cross-platform React Native app with real-time crypto prices, biometric security, and offline portfolio access. Impact: Makes crypto accessible to 340M African internet users previously locked out by traditional platforms.
